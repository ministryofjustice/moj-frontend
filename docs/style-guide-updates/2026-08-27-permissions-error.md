Show the following heading on a 403 error page, when the user does not have permission to see the page: 

You do not have permission to view this page 

Then explain: 
- what access or permission the user is lacking 
- what the user should do if they think they need that access, for example contacting the relevant team or raising a service request 
- that the user may have signed in with the wrong account, if applicable 

Give the user a clear next step to fix the problem, for example linking to: 
- the sign-in page 
- service support 
- a contact method for the team 

Develop this content with the teams in your business area that manage user permissions.
