## Overview

Sometimes services exchange or process information with legacy systems and that takes time. The spinner progress indicator component enables users to know that their request is being worked on.

### How the component is currently used

This component acts as a progress indicator between 2 screens. For example, when the submit button is selected on the final screen, the user is redirects to the spinner screen and then on to the result (success or failure).
