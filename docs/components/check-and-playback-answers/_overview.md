## Overview
Inherits the GOV.UK check your answers ‘how it works’ configured to suit LAA services which can require a user to enter a lot of information and then review this before submitting.
Inherits the GOV.UK check your answers ‘when to use this component’. 
On some LAA services it may be the case that not all sections are completed at once or by the same user. For this reason LAA services may have check your answer pages at the end of sections as well as a final check your answers before submitting the form.
Use of summary cards:
Instead of the standard GOV.UK check your answers, LAA uses summary cards because they:
make scanning easier, as you can add headings and chunk information into relevant sections
provide more flexibility for actions - in a row or the heading of a card
Page width:
Using the full-page width for the summary cards improves readability of manual entries, which may be lengthy - for example the free-text field for details under further information.
Summary cards and headings 
Summary card titles and headings allow content to be clearly signposted and segmented. This helps distinguish if there is more than one set of data entered in a form. For example in Crime Apply, the ‘client’ might have a ‘partner’, answering the same sets of questions.

### How the component is currently used

Using tags in summary cards:
When it is helpful to highlight certain important information to users who will be scanning the page, tags can be used with appropriate text and colour. Tags should be placed inside a summary row and right aligned in the row.
Confirmation:
There are times when the user needs to be asked to explicitly confirm something. eg. 
• I confirm that all costs are exclusive of VAT 
End to end service considerations - playback of answers: 
For services that enable one set of users to enter, check and submit information, and another set of users to review the information, presenting information consistently across both products (with exceptions for where user needs differ), may help avoid unnecessary confusion for both provider and case worker.
This means for (check your answer and viewing a thing) using the same:
• design layout, patterns and formatting
• order (for example, of questions presented)
• content style and patterns
• language
• labels
Long-form answers:
Long-form answers should use a single-column, half-width layout and be aligned to the left. This keeps the line length shorter and makes lengthy manual entries easier to read. This final approach was agreed following consultation with the MoJ Digital Accessibility Team in July 2026. 
Chunking information:
For some users the page can be very overwhelming / too much to look at. Headings are used to chunk the answers into the main sections.  Summary card titles are used to chunk the sub-sections.
