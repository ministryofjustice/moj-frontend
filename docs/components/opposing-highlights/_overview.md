## Overview
These styles can be used to accessibly highlight two different categories of information in the same passage of text.
 
The colours are opposed so that users with visual conditions such as colourblindness can tell the difference between them. Text decoration means that users of Windows high contrast mode, or those with low to no perception of colour can also distinguish between them.
 
Visually hidden text helps screen reader users understand the category of each highlight. For sighted users, it is recommended that a key is present on the page to define the categories.
 
The highlights can also be overlaid, users can tell that both categories apply to the highlighted text.
 
To keep the component accessible, colours and text decoration should not be changed.

### How the component is currently used

In Justice Redact, the blue style with wavy text decoration represents AI suggestions which users may wish to redact. The orange style with over and underlines represents what the user has chosen to redact.
 
If you are planning on using these styles specifically for application and removal of redactions, get in touch with the Justice Redact team to discuss patterns.
