## Service template

Use the service template for top-level pages. There are 6 variants:

1. [Service template (sections)](#service-template%28sections%29)
2. [Service template (no sections)](#service-template%28no-sections%29)
3. [Service template (horizontal search)](#service-template%28horizontal-search%29)
4. [Service template (horizontal search with tabs)](#service-template%28horizontal-search-with-tabs%29)
5. [Service template (vertical filter)](#service-template%28vertical-filter%29)
6. [Service template (vertical filter with tabs)](#service-template%28vertical-filter-with-tabs%29)

The main heading (H1) for the service template should be either: 

- the section title (if there are sections in the primary navigation)
- the service name (if there are no sections)

Add a caption if the user needs more context about where they are in the service, or the H1 does not reflect the section title or service name.

Some templates include sections in the primary navigation, these can be removed if they’re not needed.

### Service template (sections)

Use this template for top-level pages with sections in the primary navigation, and no search functionality.

### Service template (without sections)

Use this template for top-level pages with no sections in the primary navigation, and no search functionality.

### Service template (horizontal search)

Use this template for top-level pages with a horizontal search (or search and filter).

### Service template (horizontal search with tabs)

Use this template for top-level pages with a horizontal search (or search and filter) and tabs to categorise the search results.

### Service template (vertical filter)

Use this template for top-level pages with a vertical filter.

### Service template (vertical filter with tabs)

Use this template for top-level pages with a vertical filter and tabs to categorise the results.
