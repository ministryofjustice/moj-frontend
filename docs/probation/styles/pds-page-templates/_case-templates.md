## Case template

Use the case template for pages displaying a case or case details. There are 4 variants:

1. [Case template (no secondary navigation)](#-case-template%28no-secondary-navigation%29)
2. [Case template (sub navigation)](#-case-template%28sub-navigation%29)
3. [Case template (side navigation)](#-case-template%28side-navigation%29)
4. [Case template (sub and side navigation)](#-case-template%28sub-and-side-navigation%29)

The main heading (H1) on case pages, and any child pages, is the person’s name.

These templates include sections in the primary navigation, these can be removed if they’re not needed.

### Breadcrumbs and back links on case templates

The first breadcrumb should be your service name. Do not include the current page in the breadcrumbs trail.

Use back links on question pages, or in services with no sections in the primary navigation.

### Case template (no secondary navigation)

Use this template for case pages with no secondary navigation.

### Case template (sub navigation)

Use this template for case pages using sub navigation to navigate between case details. If you have multiple sections and need more space, use the side navigation template.

The H2 is the section title.

### Case template (side navigation)

Use this template for case pages using side navigation to navigate between case details. The side navigation component has space for more sections than the sub navigation component. 

The H2 is the section title.

### Case template (sub and side navigation)

Use this template for case pages using both sub and side navigation to navigate a further level of case details. 

The H2 is the sub navigation title, the H3 is the side navigation title.
