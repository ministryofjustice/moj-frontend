---
title: Results (from search)
---

Show the following heading after a user has conducted a search (with their search term in single quote marks):  

2 results for ‘Tom Wilson’ [in section, if appropriate]

You may need to help users understand what data has been searched, for example a legacy system (if you've identified a user need for this).

You can use this content pattern with the [pagination component](/components/pagination/). Pagination will also show the total results.

There's also a [content pattern for showing no results (from search)](/content-standards/style-guide/#no-results-from-search).
