---
title: reoffending predictors (previously risk predictors)

---

Use ‘reoffending predictors’ to describe the tools that predict how likely it is that a person will reoffend. Do not use ‘risk predictors’. The Public Protection Group (PPG) has advised that ‘reoffending predictors’ is clearer.

Use the full name of the predictor, where possible, rather than acronyms. The names for the predictors describe the type of reoffending they predict. Acronyms do not help users understand how to use the predictors.

Use sentence case for the names of the specific predictors:

- all reoffending predictor
- violent reoffending predictor
- combined serious reoffending predictor
- serious violent reoffending predictor
- direct contact – sexual reoffending predictor
- images and indirect contact – sexual reoffending predictor
